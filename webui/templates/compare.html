Methodology & Caveats

  • Valuation asymmetry: Anti-nero figures are effective (sum of non-cancelled payment orders where any exist, stated value otherwise); ΔΑΣΕ figures are stated contract values only — payment orders have not been harvested for that dataset yet. Effective values can run below stated for works still in progress.
  • Different universes: Anti-nero is one programme (ΥΠΕΝ, RRF Action 16849, umbrella pass-throughs excluded); the ΔΑΣΕ dataset is contractor-defined — every public contract of every buyer whose contractor is a curated forest labour cooperative, 09/2021 → today.
  • Deduplication: ΔΑΣΕ aggregates exclude cancelled rows and rows superseded by a stored amendment; Anti-nero uses its scope/supersede curation.
  • Regions: Anti-nero project regions are hand-curated from titles/PDFs and split evenly across multi-region contracts; ΔΑΣΕ regions come from the awarding unit (Δασαρχείο/Δ. Δασών/municipality), {{ cmp.dase_unresolved.n }} multi-region contracts honestly unresolved.
  • Consortiums: where a contract has several partners its value counts in full for each (max-exposure convention, same as the rest of the site).
